# Legacy site (archived)

This folder holds the original pre-Astro version of the portfolio:

- `index.html` — single-file static site
- `assets/` — its CSS, JS, images and resume copies
- `Navbar/` — early multi-page prototype
- `resume.pdf` — original resume file (now served from `public/docs/`)

It is kept for reference only. Nothing here is built or published — the live site
is generated by Astro from `src/` into `dist/` (see the root `README.md`).

Safe to delete once you no longer need to compare against the old design.
